# 🧠 Single Neuron Perceptron

This project demonstrates the implementation of a single-layer perceptron, the foundational unit of neural networks, using Python and NumPy. It serves as an educational tool to understand how a perceptron can perform binary classification tasks.

## 🚀 Features

- Implementation of a single-layer perceptron from scratch
- Binary classification on linearly separable data
- Visualization of decision boundaries
- Step-by-step explanations within the notebook

## 🧑‍💻 Technologies Used

- Python 3.x
- NumPy
- Matplotlib
- Jupyter Notebook

## 📦 Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/raj4thakur/single-neuron-perceptron.git
   cd single-neuron-perceptron
   ```

2. **Create and activate a virtual environment (optional but recommended):**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install the dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Launch the Jupyter Notebook:**
   ```bash
   jupyter notebook perceptron.ipynb
   ```

## 📝 Usage

- Open `perceptron.ipynb` in Jupyter Notebook.
- Run the cells sequentially to:
  - Understand the theory behind perceptrons.
  - See the implementation details.
  - Visualize how the perceptron learns to classify data.

## 📊 Dataset

The notebook uses a synthetic dataset generated using NumPy for demonstration purposes. This dataset is linearly separable, making it suitable for a single-layer perceptron.
